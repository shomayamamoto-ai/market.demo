# 日本市場シミュレーター

日本の公的統計から「仮想の生活者(ペルソナ)」を作り、
お題や資料に対する市場の反応を試算するツールです。

## できること

| 区分 | 画面 | 内容 |
|---|---|---|
| 仮想の日本 | 人口とペルソナ | 年齢・性別・居住地の比率を保ったまま、日本を1万人(変更可)に縮小して再現。就業・年収・世帯・支出・貯蓄・ネット利用・価値観を付与し、公表値とのずれを検算表で表示 |
| 仮想の日本 | 市場の規模感 | 産業別の売上、小売の業種別・業態別販売額、ネット通販の市場規模、家計の支出 |
| 市場を試す | お題と市場規模 | お題と資料(PDF・テキスト)からAIが商品条件を読み取り、対象人口・購入見込み・売上の目安を計算。ペルソナへのAIインタビューも実行 |
| 市場を試す | 発売後の広がり | 広告と口コミによる普及を月ごとに計算し、複数回の試行で結果の幅を表示 |
| 市場を試す | 3Dで見る | ペルソナ1人ずつが島を歩き、選んだゲートに並ぶ様子を表示。A案・B案の比較も可能 |
| 市場を試す | 経営ゲーム | 3か月ごとに価格と広告費を決めて進めるターン制 |
| 市場を試す | レポート | 読み手(企画検討/社内説明/金融機関/投資家)に合わせたレポート |
| 制度を試す | 職場のルール | 給与と仕事の回し方が、働き方と生産力をどう変えるかを検証 |
| 制度を試す | 税率と助け合い | 税率と保障の仕組みが、挑戦する人の数と生産力をどう変えるかを検証 |
| 制度を試す | 多重下請け | 予算が現場に届くまでに抜かれる段階の数が、現場の人数と工事の出来をどう変えるかを検証 |
| 経済と行動 | 物価と賃金 | 物の値段と給料のルールが、消費・雇用・生産力をどう変えるかを検証 |
| 経済と行動 | 貯金と町 | 住民が使うか貯めるか、貯めたお金がどこへ行くかで、町の大きさがどう変わるかを検証 |
| 経済と行動 | 交換と略奪 | 交換・略奪・仕返し・年貢といったふるまいが、島全体の人口をどう変えるかを検証 |
| 経済と行動 | 村の決め方 | 王が決める村・多数決の村・選ばれた長の村の、豊かさと生き残りを検証 |
| 経済と行動 | 学び方 | 数をこなす人とふり返る人のどちらが上へ行けるかを、山の形を変えて検証 |
| 出典と仮定 | 出典と仮定 | データの出典と確かさ、モデルに置いた仮定、限界の一覧 |

「想定する年」を2030〜2070年に切り替えると、将来推計人口に合わせて試算できます。

## 使い方

Node.js 20 以上が必要です。

```bash
npm install
```

```bash
npm start
```

ブラウザで http://localhost:3000 を開きます。

### AIモード(お題の読み取り・AIインタビュー)を使う場合

Claude API のキーを環境変数に設定してから起動します。
キーはサーバー側だけで使い、ブラウザには渡しません。

```bash
ANTHROPIC_API_KEY=(あなたのAPIキー) npm start
```

キーが無くても、統計モード(①②④⑤と、③の手入力)はそのまま動きます。
使うモデルは環境変数 `SIM_MODEL` で変更できます(既定は `claude-opus-5-5`)。
AIインタビューは人数に比例してAPI利用料がかかります。

## 結果を読むときの注意

- ペルソナは統計の分布に合わせて乱数で作った仮想の人です。実在の個人のデータは使っていません。
- 価値観や普及の係数など、統計に無い部分は仮定で補っています(画面の「出典と仮定」に一覧)。
- ネット通販の市場規模は、検索結果の抜粋から取っており、原表との照合が済んでいません。
- AIインタビューは実際の調査の代わりにはなりません。
- 結果は「桁の感覚」と「条件を変えたときの差」を見るためのもので、売上の予測値ではありません。
