# 日本市場シミュレーター

日本の公的統計から「仮想の生活者(ペルソナ)」を作り、
お題や資料に対する市場の反応を試算するツールです。

## できること

| 画面 | 内容 |
|---|---|
| ① 人口とペルソナ | 年齢・性別の人口比を保ったまま、日本を1万人(変更可)に縮小して再現。1人ずつに居住地・就業・年収・世帯・月々の支出・ネット利用・価値観を付与 |
| ② 市場の規模感 | 産業別の売上、小売の業態別販売額、ネット通販の市場規模、家計の支出 |
| ③ お題シミュレーション | お題と資料(PDF・テキスト)を入れると、AIが商品条件を読み取り、対象人口・購入見込み・売上の目安を計算。ペルソナ1人ずつへのAIインタビューも実行 |
| ④ 普及シミュレーション | 発売後の広がりを月ごとに計算(広告で知る → 周りを見て買う → 口コミで広がる)。乱数を変えて複数回試し、結果の幅も表示 |
| ⑤ 経営ゲーム | 3か月ごとに価格と広告費を決めて進めるターン制。競合参入・SNSでの話題化などの出来事が発生 |
| 出典と仮定 | 使ったデータの出典と確かさ、モデルに置いた仮定、限界の一覧 |

「想定する年」を2030〜2070年に切り替えると、将来推計人口に合わせて試算できます。

## 使い方

Node.js 20 以上が必要です。

```bash
npm install
```

```bash
npm start
```

ブラウザで http://localhost:3000 を開きます。

### AIモード(お題の読み取り・AIインタビュー)を使う場合

Claude API のキーを環境変数に設定してから起動します。
キーはサーバー側だけで使い、ブラウザには渡しません。

```bash
ANTHROPIC_API_KEY=(あなたのAPIキー) npm start
```

キーが無くても、統計モード(①②④⑤と、③の手入力)はそのまま動きます。
使うモデルは環境変数 `SIM_MODEL` で変更できます(既定は `claude-opus-5-5`)。
AIインタビューは人数に比例してAPI利用料がかかります。

## しくみ

```
data/raw/*.json      収集した統計(出典URL・検算結果つき)
scripts/build_data.py  ↑ を1つにまとめて data/japan.json を作る
public/js/personas.js  合成人口(ペルソナ)の生成
public/js/market.js    市場規模の計算、AIインタビュー結果の集計、将来人口
public/js/diffusion.js 普及シミュレーション(Bassモデル+採用者5区分)
src/llm.js             Claude API の呼び出し(サーバー側)
server.js              画面の配信とAPIの中継
test/model.test.js     統計との検算テスト(npm test)
```

## 結果を読むときの注意

- ペルソナは統計の分布に合わせて乱数で作った仮想の人です。実在の個人のデータは使っていません。
- 価値観や普及の係数など、統計に無い部分は仮定で補っています(画面の「出典と仮定」に一覧)。
- 産業別の売上など一部の数値は、検索結果の抜粋から取っており、原表との照合が済んでいません。
- AIインタビューは実際の調査の代わりにはなりません。
- 結果は「桁の感覚」と「条件を変えたときの差」を見るためのもので、売上の予測値ではありません。
